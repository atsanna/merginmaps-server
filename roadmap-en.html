Available today

What already works

Backend features ready and covered by tests; the web interface comes in the next steps.

  • Multiple workspaces stored in the database
  • Guest, reader, editor, writer, admin and owner roles, with per-project permissions
  • Create, update and close workspaces, permanently removed after expiration
  • Per-workspace storage quota and usage summary
  • Member management: list, role change, removal, leaving
  • E-mail invitations with expiry, resend, accept and decline
  • Sign-up from an invitation link even with self-registration disabled
  • Editor role: data edits without touching the QGIS project structure
  • Automatic migration of an existing Community server
  • APIs compatible with the QGIS plugin, mobile app and Python client
  • Guest invitations to selected projects and project sharing with any e-mail
  • Per-workspace contributors limit and workspace administration API
  • Project transfer between workspaces (API)
  • Audit log and signed per-workspace webhooks (API)
  • SAML/OIDC single sign-on through Ory Polis, compatible with QGIS plugin and mobile app
  • Web maps: version processing and WMS through QGIS Server (API)
  • Web interface for workspaces, members, invitations, transfers, webhooks, activity, map and SSO
  • Shared maps with public link, embedding and OGC services

Out of scope

What this fork will not do

  • Mandatory telemetry to Mergin Maps: this fork sends no statistics
  • Subscriptions, billing and cloud service plans
  • Basemaps hosted by Mergin Maps
  • Proprietary Enterprise Edition code or images
